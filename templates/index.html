Cryptographic Architecture & Security Specifications

Formal cryptographic guarantees and engineering standards built into this implementation.

NIST SP 800-38D / PKCS#1 v2.2

Symmetric Stream Encryption

AES-256-GCM authenticated encryption with cryptographically secure 96-bit random nonce per session. 128-bit authentication tag guarantees tamper detection.

Asymmetric Key Encapsulation

RSA-3072 with OAEP padding (SHA-256) wrapping the AES session key. Exceeds standard 2048-bit security for long-term protection.

Content-Bound Signatures

RSA-PSS with SHA-256 and maximum salt length. Signatures bind both metadata headers and a rolling SHA-256 stream of the ciphertext.

Zero-Memory Sanitization

Direct low-level C-memory clearing via ctypes.memset wipes password buffers and AES keys from physical RAM immediately upon use.

Chunked Stream Processing

Chunked 64 KB stream pipeline prevents RAM exhaustion when encrypting or decrypting large files up to NIST limits (~64 GB).

OS-Level Key Vault

Private keys stored with restricted ACL permissions in user profile (~/.cypher_lock/) with atomic file replacements.

Critical Warning

Keys already exist. Overwriting them will make all previously encrypted files permanently unrecoverable.
